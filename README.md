Edit Vault
Edit Vault is a full-stack web application designed to provide users with a centralized and convenient way to securely store, manage, edit, and organize their digital files. The platform supports multiple file types, including documents, images, videos, and audio, while providing an easy-to-use interface for accessing and managing files.


Key Features
Secure File Upload: Upload and store files securely within the vault.
File Preview: Preview images, videos, and audio files directly without downloading them.
File Management & Editing: Edit and update files while keeping them organized in the vault.
File Downloads: Download individual files whenever needed.
Shopping Cart: Add multiple files to a cart and manage them for convenient bulk downloading.
Download History: Track previously downloaded files and download them again when required.
Responsive Interface: Designed to provide a smooth experience across desktop, tablet, and mobile devices.
Technologies Used

Technologies Used
Frontend: React.js, Material-UI, Axios, React Context API
Backend: Node.js, Express.js
Database: MongoDB

Project Highlights
Developed a responsive full-stack file management platform with separate frontend and backend architecture.
Implemented centralized state management using React Context API for features such as the shopping cart.
Integrated REST APIs using Axios and Express.js for communication between the frontend and backend.
Used MongoDB to manage file metadata and user-related information.
Built a user-friendly interface for uploading, previewing, editing, organizing, and downloading different types of files.
